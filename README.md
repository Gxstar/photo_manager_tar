# 显影（develop）

插上相机 SD 卡 → 扫描 → 跳过库里已有的 → 按拍摄月份归档进 `原图\` / `视频\`。
个人本地工具，单机单用户，**默认不联网**（仅地点相册有两个可选在线服务，见下）。**只读只约束 SD 卡导入阶段，进入网格页面就是图片管理**：

- **导入阶段（SD 卡 → 媒体库）只读**：不改相机原厂文件名、绝不覆盖已有文件、绝不删卡上文件。
- **图库阶段（网格页）允许管理操作**：原则上可对库内文件做删除、重命名等；评分、收藏、废片标记仍只存本地 SQLite，不写回照片文件。
- **智能相册 / 语义搜索（骨架已接入，AI 能力尚未实现）**：按人、宠物、GPS 地点组织相册，并支持中文语义搜图（如「夕阳下的河」）。作为**可整体关闭的独立模块**实现：模型与推理全在本机，索引只写独立的 `smart.db`，绝不写回照片文件、不移动 / 不改名；人物与宠物等身份特征属敏感数据，可单独清除。范围与硬边界见 `docs/开发方案.md` §17，UI 规格见 §19。
  当前已落地：侧边栏入口、**页内「人物 / 地点 / 地图」分段（各段只呈现自己的工具与网格；扫描 GPS、解析地名只在地点段；语义搜图入口移到图库搜索浮层，docs §36 / §37）**、独立 `smart.db`、EXIF GPS 扫描与地点相册（**JPG 与 RAW 各算一张，缩略图左下角有 `RAW` 格式角标**，与视频的 `MP4` 角标同位置）、4:3 封面卡（含 RW2 内嵌预览兜底）、**相册详情视图（点卡片进入，返回回到列表；人物 / 宠物 / 地点三类相册共用同一套行为，网格支持右键菜单，与图库同一套）**、全幅 Leaflet 地图（高德瓦片，免 key）、
  模型就绪门禁与手动放入目录、**天地图逆地理编码（省 / 市 / 县三级，需在设置里自填 key 并点「解析地名」）**；
  **人物相册（手动建册）已实现**：新建 / 重命名 / 删除人物，图库选中照片批量「关联到人物」，人物卡进详情查看、取消关联；只写 `smart.db` 的 `albums` / `album_members`（`kind='person'`、`source='user'`），不改照片文件。空数据、重复关联 / 取消、重名、文件缺失、读取失败均有明确提示与处理，规格见 `docs/开发方案.md` §35。
  **语义搜图、人物 / 宠物自动识别（人脸模型）、内置模型下载仍未实现**，界面按真实状态（空态 / 灰显 / 禁用）呈现，绝无假数据；语义搜图的门禁状态可在图库工具条的搜索浮层里查看（模型状态按需检测、失败可重试）；删除照片文件仍走「标记废片 → 废片复核 → 系统回收站」。
  详见 `docs/开发方案.md` §20 / §21 / §22 / §35。
- **联网白名单（默认关闭，用户显式启用）**：仅三类用途 ——「天地图逆地理编码」（用户自填 key）、「地图瓦片」（给 GPS 相册取名 / 看图）、「模型下载」（用户在设置页主动点下载才联网，**不自动、不后台**；也支持自行下载后**手动放入模型目录**）；前两者**只发送坐标，绝不上传图片 / 文件名 / 路径 / 向量 / 人脸数据**，模型下载只做文件拉取。未启用或失败时降级为坐标显示 + 手动命名；未下载模型时 AI 功能灰显不可用。详见 `docs/开发方案.md` §17.13 / §17.15。

删除沿用「列清单 + 二次确认 + 系统回收站」的可恢复流程；重命名不得覆盖同名文件。详见 `docs/开发方案.md` §16。

技术栈：Tauri 2 + Vue 3 + Vite + Tailwind CSS 4（前端）/ Rust（全部文件 IO）。

## 开发

```bash
npm install          # 首次
npm run tauri dev    # 开发模式（自动起 Vite + Rust 编译）
```

> 前提：安装 Rust 工具链（[rustup](https://rustup.rs)，MSVC target）；若命令行找不到 `cargo`，把 `%USERPROFILE%\.cargo\bin` 加入 PATH。
>
> 运行单元测试（可选）：测试用真实媒体库做只读夹具，设置环境变量 `SDI_FIXTURE_ROOT` 指向媒体库根目录，未设置时相关测试自动跳过。

## 打包

```bash
npm run tauri build  # 产出 NSIS 安装包（src-tauri/target/release/bundle/）
```

## 归档规则

- 目录结构：`{库根}\{原图|视频}\{YYYY}\{YYYY-MM}\原文件名`，年月目录自动创建
- 拍摄时间来源（降级链）：EXIF（RW2 走内嵌 APP1）→ MP4/MOV mvhd（1904 纪元换算）→ 文件名 `IMG_YYYYMMDD_HHMMSS` → 文件创建时间
- 无法确定时间 → `原图\待定\`；月份缺口是正常历史状态，不报错
- 去重 = 目标路径存在性检测（文件名 + 月），同名同大小跳过、不同大小标冲突，**绝不覆盖**；拷贝不改动库内已有文件（导入阶段只读；图库阶段的管理操作见下方）
- 图库评分存本地 SQLite（`gallery.db`），不写入照片文件；需要与其它看图软件交换时，可在设置页手动导出 XMP sidecar
- sidecar（xmp/acr/pp3）跟随主文件同月归档
- 忽略 `desktop.ini` / `Thumbs.db` / `$RECYCLE.BIN` / `PRIVATE` 等系统目录

## 废片复核（当前唯一已实现的删除入口）

网格页原则上已允许删除、重命名，但**目前只落地了下面这条删除流程**；直接删除与重命名入口尚未实现，别把原则放宽当成功能已具备。

- 看片时按 `X` 或右键「标记废片」：只写本地 SQLite，文件不动，但从网格视图隐藏
- 工具条「废片 N」打开复核清单：可逐项「还原」（取消标记），或勾选后二次确认「移入回收站」
- 删除走系统回收站、可还原；不会永久删除，绝不自动删，绝不碰 SD 卡上的文件
- **建议先清卡再清理废片**：判重只看目标路径是否存在，卡未清时被删的文件下次扫描会按「新增」重新拷回
- 图库工具条的放大镜是文件名搜索：输入片段后回车跳到对应照片并选中，多个同名匹配可逐个切换

设计细节与实测依据见 `docs/开发方案.md`。
